# 复现与修复记录（2026-11-02）

环境：macOS arm64、Apple M3、Node.js v22.12.0。以下结果来自当前工作区，包含任务开始前已有的未提交修改。

## 快照一致性

命令：

```sh
node --test tools/tests/xsxb_mcp_observation_race.test.js
```

通过公开 JSON-RPC `tools/call` 查询动画、测量帧和导出拼图。在操作前哈希读取 PNG 后，用文件读取钩子立即把红色 PNG 替换为绿色 PNG，确定性模拟外部写入。

修复前三项调用仍返回成功，三项测试失败；未改源文件的对照测试通过。原因是操作后校验被 `readOnlyObservation` 跳过，预检缓存也无法用于发现外部变化。

修复后，在返回观察结果前独立重算内容快照，变化时返回 `STALE_SNAPSHOT`；四项测试通过。外部修改保留，未变化的输入继续返回相同快照 ID。此修复恢复前后两遍内容校验，相比跳过校验的版本会增加读取成本。

## PNG 路径导入

命令：

```sh
node --test tools/tests/xsxb_mcp_video_import.test.js tools/tests/xsxb_mcp_inplace.test.js
```

PNG 序列、items 路径、SpriteFrames 三种入口，分别覆盖普通导入和 `in_place`。修复前六项测试均捕获到不必要的 PNG base64 编码；修复后使用底层已有的 `sourcePath` 逐帧读取，全部通过。损坏后续帧的测试同时验证原有文件保留及暂存清理；本组共 20 项通过。

500 帧隔离子进程实验使用 512×512 PNG，每帧 340409 字节。旧 helper 仅在对照子进程中注入；两组导入结果均与源文件逐字节相同。

| 指标                |    修复前 |    修复后 |
| ------------------- | --------: | --------: |
| PNG base64 编码次数 |       500 |         0 |
| 峰值 RSS            | 629.1 MiB | 286.4 MiB |
| 导入耗时            |   12.03 s |   11.75 s |

耗时为单次样本，测量期间还有其他并行任务，不能据此承诺稳定吞吐收益。

## GIF 视觉变换内存

命令：

```sh
node --test tools/tests/xsxb_mcp_gif_memory.test.js
node --expose-gc tools/tests/xsxb_mcp_gif_memory.test.js --probe 100 512
```

修复前，40 帧 256×256 的活跃像素缓冲区预算测试失败，保留约 20 MiB；原实现同时持有整组源帧和目标帧。修复后逐帧解码、放置、写入，保留首个选中帧的画布尺寸。

100 帧 512×512、视觉倍率 0.75 的对照：

| 指标                  |      修复前 |     修复后 |
| --------------------- | ----------: | ---------: |
| 存活 ArrayBuffer 峰值 | 209884912 B |  3593968 B |
| 进程峰值 RSS          |  351.73 MiB | 219.94 MiB |

前后逐帧 PNG SHA-256 相同。另有混合尺寸、禁用帧和逐帧倍率测试，与原批处理输出逐字节比较。测量在每次写入视觉帧后强制 GC，用来辨别整组像素保留；GIF 编码为替身，真实像素处理管线保留，RSS 不代表普通运行的固定收益。

## 执行期间 ping 测量

命令：

```sh
node --test tools/tests/benchmark_mcp.test.js
npm run benchmark:mcp
```

旧基准在业务微任务开始前就发出了 ping。60 ms 同步阻塞工具仍测得 0.47 ms，复现测试失败。

修复后，服务运行在独立子进程；控制端收到执行开始标记后，通过 STDIO 发送 ping，并用执行窗口时间戳报告 `pingIssuedDuringTool`。同步阻塞、异步可响应和服务提前退出三项测试通过。

当前合成视频导入基准使用 FFmpeg 提取替身：

| 帧数 |      导入 | 执行期间 ping | 摘要中位数 | 服务峰值 RSS |
| ---- | --------: | ------------: | ---------: | -----------: |
| 100  |  807.8 ms |      807.2 ms |    41.0 ms |    193.8 MiB |
| 500  | 3941.2 ms |     3940.6 ms |   201.7 ms |    284.5 MiB |

本轮所有 ping 样本均在执行窗口内。摘要前后两遍 PNG 校验分别读取 200 / 1000 次。该测量明确显示同步处理仍会阻塞主线程。
